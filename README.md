# 🍽️ Sabor Express — Restaurant Management App

A simple console-based restaurant management application built with Python during **Alura’s** *“Python: Crie sua primeira aplicação”* course.

## 📖 Overview

**Sabor Express** allows users to:
- 📌 **Register new restaurants**
- 📋 **List all registered restaurants**
- 🔄 **Toggle a restaurant’s status (Active/Inactive)**
- ❌ **Exit the application**

The application manages restaurant data using a Python list of dictionaries, providing a clean and interactive command-line experience.

## 🛠️ Technologies

- Python 3.x  
- `os` module (for clearing the console screen)

## ▶️ How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/sabor-express.git
   cd sabor-express
   ```

2. **Run the application**
   ```bash
   python app.py
   ```

> ✅ *Note: The `os.system('cls')` command is for Windows.  
> If using macOS or Linux, replace `cls` with `clear` in the code.*

## ✨ Features

- Clean, interactive command-line interface.
- Modular, easy-to-read code structure.
- Real-time restaurant status toggling.
- Organized restaurant listing by name, category, and status.
